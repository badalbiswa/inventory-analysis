Toy Store Inventory Analysis
A Python project that cleans and analyzes inventory data for Rainbow Shelf Toys. It removes invalid and duplicate records, standardizes dates and costs, and calculates inventory value, stock age, category totals, and low-stock items.
Key findings
- Total inventory value was $36,758.67.
- As of July 6, 2026, 20 SKUs had been on the shelf for more than 90 days, representing $29,275.29 in inventory value. Six SKUs without usable receipt dates were excluded from the aging calculation.
- One SKU had fewer than five units in stock.
Project files
File	Purpose
[`analysis.py`](analysis.py)	Cleans the raw data, calculates inventory metrics, and generates the output files.
[`clean_inventory.csv`](clean_inventory.csv)	Cleaned inventory records.
[`inventory_analysis.xlsx`](inventory_analysis.xlsx)	Excel workbook containing the inventory analysis.
[`supplier_notice.docx`](supplier_notice.docx)	Supplier notice generated by the script.
[`answers.md`](answers.md)	Detailed findings and data-cleaning notes.


Run locally
The script requires the original inventory_raw.csv, which is absent from the project files provided. Place it alongside analysis.py and run these commands from that folder.
python -m pip install "pandas>=2.0" openpyxl python-docx
python analysis.py
